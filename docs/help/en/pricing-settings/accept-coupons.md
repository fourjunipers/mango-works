# Switch coupons on or off for the shop

**Accept coupons** is one switch for the whole shop. Off: no code takes anything off, on any channel. Coupons are made in Settings › Coupons.

Who can do this: owners and managers.

## Steps

1. Open **Shop settings** and choose **Pricing and tax**.
2. Under **Coupons**, tick or untick **Accept coupons**.
3. Press **Save pricing settings**.

While it is off, **Settings › Coupons** says "The shop doesn’t accept coupons right now, so no code takes anything off. You can still create and edit coupons." You can still create and edit coupons.

The returning-customer discount is not affected by this switch.

## Common problems

- A code tried in **Check a price** says **"Not applied: the shop doesn’t accept coupons. Switch on “Accept coupons” in Settings › Pricing and tax."** Switch it on as above.
