# Switch coupons on or off for the shop

**Accept coupons** is one switch for the whole shop. Off: no code takes anything off, on any channel. Coupons are made in Settings › Coupons.

A new shop starts with it off. Switch it on before your first coupon can work.

Who can do this: owners and managers.

## Steps

1. Open **Shop settings** and choose **Pricing and tax**.
2. Under **Coupons**, tick or untick **Accept coupons**.
3. Press **Save pricing settings**. **Saved** appears.

While it is off, **Settings › Coupons** says "The shop doesn’t accept coupons right now, so no code takes anything off. You can still create and edit coupons." You can still create and edit coupons, for example get SONGKRAN10 ready before you switch coupons on.

The returning-customer discount is not affected by this switch.

## Common problems

- A code tried in **Check a price** or the **Price check** says **"Not applied: the shop doesn’t accept coupons. Switch on “Accept coupons” in Settings › Pricing and tax."** Switch it on as above.
- **"Couldn't save. Please try again."** Reload the page and try again.
