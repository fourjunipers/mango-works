# Change, switch off or archive a coupon

**Settings › Coupons** lists every coupon with its code, discount, status (**On**, **Off** or **Archived**) and how often it has been used.

The uses read "Used {used} of {limit}" when the coupon has a **Total uses** limit, and "Used {used}" when it has none. Every coupon shows its uses, archived ones too. If a new coupon now has the code of an archived one, each keeps its own count: the archived coupon shows only the bookings that used it.

| Status | What it means |
| --- | --- |
| **On** | Customers can use its code. |
| **Off** | Its code takes nothing off until it is switched on. You can still edit it. |
| **Archived** | It can no longer be used or changed, and its code is free for a new coupon. Bookings that used it keep their discount. |

There is no delete: archive instead.

Who can do this: owners and managers.

## Change a coupon

1. Open **Shop settings** › **Coupons** and press **Edit** on the coupon.
2. Change what you need.
3. Press **Save coupon**. **Saved** appears.

The coupon's page shows its **History**: every change and who made it, for example "Nok switched off SONGKRAN10". The **Coupons** page shows the history of all coupons.

## Switch it off or on

Press **Switch off** (or **Switch on**) on the coupon's row or on its page. For example, switch SONGKRAN10 off after the festival and on again next April.

## Archive it

1. Press **Archive**.
2. Confirm "Archive {code}? It can no longer be used, and its code becomes free for a new coupon. Bookings that used it keep their discount."

## Bring back an archived coupon

1. Press **View** on the archived coupon.
2. Press **Bring back**. It becomes usable again, unless another coupon has its code now.

## Common problems

- **"Another coupon already uses the code {code}. Archive it first, or choose another code."** Or **"The coupon “{name}” already uses the code {code}. Archive it first, or choose another code."** Another live coupon took this code meanwhile. Archive that one first, or change this coupon's code.
- **"This coupon no longer exists. Reload the page."**
- **"Someone is making a booking with this coupon right now, so nothing was saved. Please save again."** Nothing was changed. Press the same button again.
- **"Only an owner or a manager can change coupons."**
- For the form's other messages, see [Create a coupon](create-a-coupon.md).
